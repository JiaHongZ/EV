# EV

Official implementation of EV for ImageNet experiments.

## Repository layout

The implementation, training scripts, evaluation scripts, and supporting code are in [`EV-ImageNet/`](EV-ImageNet/).

## Dependencies

This project is built on [PyTorch Image Models (timm)](https://github.com/huggingface/pytorch-image-models). The required source snapshot is included under `EV-ImageNet/timm`.
